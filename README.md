# learning_offensive_security

A personal collection of tools, scripts, and exercises developed while learning offensive security, penetration testing, and red team fundamentals.

This repository contains practical utilities, automation tools, and training scripts used in CTFs, labs (HTB/THM), and OSCP-style environments.

## 🧰 Tools

### 🔹 Automation

* **credgen**
  Generates authentication commands for multiple protocols (SSH, SMB, RDP, WinRM, etc.)

* **loot-organizer**
  Organizes pentesting loot into structured categories (credentials, hashes, configs, etc.)

---

### 🔹 Information Gathering

* **subdomain_ct_log**
  Extracts subdomains from Certificate Transparency logs

---

### 🔹 Web Enumeration

Collection of scripts focused on web reconnaissance and enumeration.
